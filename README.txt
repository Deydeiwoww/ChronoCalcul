ChronoCalc — version hors ligne

Contenu :
- index.html : application complète
- manifest.webmanifest : métadonnées de l'application
- sw.js : cache hors ligne
- icon.svg : icône

Installation sur iPhone :
1. Hébergez ces fichiers sur un site HTTPS (par exemple GitHub Pages).
2. Ouvrez l'adresse dans Safari et attendez le premier chargement complet.
3. Appuyez sur Partager > Sur l'écran d'accueil.
4. Ouvrez ChronoCalc une fois pendant que vous avez Internet, pour que les fichiers soient mis en cache.
5. Vérifiez ensuite le fonctionnement en activant le mode Avion.

Important : le premier hébergement et chargement nécessitent Internet. Après mise en cache, les calculs se font localement et fonctionnent hors ligne. iOS peut parfois purger le cache d'un site ; pour une garantie de conservation plus forte, une vraie application native nécessiterait une chaîne de compilation/signature iOS.
